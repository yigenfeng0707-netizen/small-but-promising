# Archive - 一次性脚本归档

此目录存放项目开发过程中使用的一次性调试/部署脚本，保留供参考，不参与项目构建。

## 脚本清单

| 脚本 | 用途 |
|------|------|
| `_browser_deploy.py` | 浏览器自动化部署到魔搭创空间 |
| `_check_studio.py` | 检查魔搭创空间状态 |
| `_configure_ms.py` | 配置魔搭创空间环境变量 |
| `_deep_restart.py` | 深度重启服务 |
| `_force_deploy.py` | 强制部署 |
| `_generate_ppt.py` | 生成 PPT 演示文稿 |
| `_get_logs.py` | 获取服务日志 |
| `_push_via_gh_api.py` | 通过 GitHub API 推送代码 |
| `_try_deploy.py` | 尝试部署 |
| `_try_restart.py` | 尝试重启 |

## 说明

这些脚本在项目开发过程中用于调试和部署，功能已被 GitHub Actions 工作流替代。
保留在此目录仅供后续参考，不影响项目运行。
