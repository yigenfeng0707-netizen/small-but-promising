## 第 2 页 · 一个被忽视的"家里的事"

**标题**：痛点 —— 家里最危险的地方，可能是水槽下

**要点**：
- 我国家庭化学品急性中毒事件中，**儿童误服占比 > 40%**，1-4 岁最高发
- 农村独居老人因看不懂标签、子女不在身边，风险显著更高
- 市面缺乏"拍一下就知道安不安全"的轻量工具
- 老人面对"次氯酸钠""烷基苯磺酸钠"无从判断危险

**配图建议**：左侧一张水槽下塞满清洁剂的真实照片，右侧一张儿童误服的新闻截图（脱敏），形成视觉冲击。

## 第 3 页 · 我们的方案：安居智评 Agent

**标题**：方案 —— 拍一下，10 秒知道安不安全

**要点**：
- 一句话方案：**拍一张照 / 说一句话，得到针对这瓶化学品 + 这个家庭的完整安全评测与应急方案**
- 三种入口：拍照（低识字友好）/ 语音（老人视障友好）/ 文本（二次提问）
- 全链路 6 步：识别 → 成分解析 → 风险评测 → 家庭画像 → 场景建议 → 应急指导
- 用户只需一次交互，系统自动跑完 6 步

**配图建议**：手机界面三联图——拍照界面 / 语音波形界面 / 结果页风险等级高亮，体现"三入口"。

## 第 5 页 · 6 Agent 全链路流程图

**标题**：6 Agent 协作 —— 从识别到应急，端到端覆盖

**要点**：
- Step1 识别 Agent（Qwen-VL）→ Step2 成分解析（Qwen3 + RAG）
- Step3 风险评测（5 维评分）→ Step4 家庭画像（个性化上调）
- Step5 场景建议 ‖ Step6 应急指导（**并行**，省 30% 延迟）
- 任一 Agent 失败 → 降级返回部分结果，不拖垮整次评测

**配图建议**：横向流程图，6 个圆角矩形节点依次连接，Step5/Step6 用分叉箭头表示并行。每个节点下方一行小字标注"调用的模型 / 知识库"。

## 第 6 页 · 6 Agent 职责一览表

**标题**：6 Agent 各司其职，职责单一可独立调用

**要点**（表格形式）：

| Agent | 职责 | 关键产出 |
|-------|------|----------|

| 应急指导 Agent | 误服/误触/泄漏处置 | 应急步骤 + 一键呼救 |

## 第 7 页 · 知识库与 RAG：让评测有据可查

**标题**：MSDS 知识库 —— 58 条真实数据，防大模型幻觉

**要点**：
- 58 条 MSDS 数据，覆盖 6 类：清洁剂/消毒剂/杀虫剂/药品/化妆品/其他
- 本地精确 + 模糊匹配 RAG，离线可跑，不依赖外部 Embedding
- 风险评测 Agent **必须优先引用 MSDS 命中片段**，未命中时显式标注
- 公益机构可按需追加 JSON 条目，知识库可持续扩充

**配图建议**：左侧 6 类化学品的图标饼图，右侧一条"成分 → RAG 命中 → 风险评分依据"的引用链路示意图。
