## 录制注意事项

### 一、录制前准备

1. **跑通真实链路**：在 `backend/.env` 填入真实 `DASHSCOPE_API_KEY`，本地或线上 Demo 跑通三种场景，确认结果正常再录
2. **关闭干扰**：关闭浏览器通知、电脑弹窗、手机消息，录屏区域只保留浏览器窗口
3. **浏览器准备**：用 Chrome / Edge 全屏（F11），缩放 110% 让界面元素更清晰
4. **网络稳定**：确保网络畅通，避免加载卡顿；建议先预演一遍全部流程
5. **家庭画像预设**：场景一录之前，先在家庭画像设置页填好「5 岁儿童」并保存

### 二、录制中要点

1. **语速放慢**：每分钟 ~200 字，关键信息（"极高""剧毒""严禁混用"）加重音
2. **节奏对应**：旁白和屏幕动作要同步，旁白说到什么屏幕就显示什么
3. **关键信息停留**：风险等级徽章、警告框、绿色替代品卡片出现时，停留 1-2 秒让观众看清
4. **鼠标引导**：屏幕动作时用鼠标光标缓慢指向关键区域，给观众视觉引导
5. **失败重来**：单个场景失败不必从头录，可在剪辑时拼接；但旁白建议一次录完保证连贯

### 三、录制后剪辑

1. **拼接顺序**：开头 → 场景一 → 场景二 → 场景三 → 结尾
2. **背景音乐**：开头和结尾加舒缓钢琴/吉他纯音乐，音量 -20dB，不盖过旁白
3. **字幕**：建议加中文字幕（可用剪映自动识别 + 人工校对），照顾静音观看
4. **导出格式**：MP4，1080p，码率 8-10 Mbps，文件大小控制在 200MB 以内
5. **文件命名**：`安居智评_Demo_v1.mp4`

### 四、上传与提交

1. 上传到 B 站 / 腾讯视频 / YouTube（任选一），设置为**公开**或**仅限链接访问**
2. 复制视频链接，填入赛事提交表单
3. 同时保留本地 MP4 文件备份，以防链接失效
