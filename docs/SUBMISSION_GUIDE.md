## 五、用户必须本人完成的事项

以下事项**无法由代码生成**，必须用户本人操作。请按顺序逐项完成：

### a) 赛事报名（表单）

- 访问赛事官网或提交地址，完成报名表单
- 登录阿里云账号（若无则注册）
- 填写团队信息、参赛赛道（绿色发展赛道）、项目名等

### b) 领取百炼 1 亿 Token（新用户）

- 访问 [阿里云百炼控制台](https://bailian.console.aliyun.com/)
- 新用户可领取 **1 亿 Token** 免费额度（赛事补贴）
- 在控制台创建 API Key，复制保存（形如 `sk-xxxxxxxx...`）
- 把 API Key 填入 `backend/.env` 的 `DASHSCOPE_API_KEY` 字段

> 老用户若已有 DashScope API Key 可直接复用，无需重新领取。

### c) 在 backend/.env 填入真实 DASHSCOPE_API_KEY 跑通真实链路

- 编辑 `backend/.env` 文件，把 `DASHSCOPE_API_KEY=your-key-here` 替换为真实 Key
- 重启后端：`uvicorn backend.main:app --reload`
- 测试三种入口是否返回真实评测结果（非降级兜底）：
  - 拍照评测：上传一张洁厕剂照片，确认返回识别 + 风险 + 绿色替代品
  - 语音评测：输入"84 消毒液和洁厕灵能混用吗"，确认返回氯气警告
  - 文本评测：输入"管道疏通剂"，确认返回 5 维风险评分

### d) 部署到 Zeabur/Railway 拿到线上 Demo 地址

- 参考 `docs/DEPLOY.md`，推荐用 Zeabur（国内访问快）
- 推送代码到 GitHub 公开仓库
- Zeabur 控制台导入仓库，自动识别 `zeabur.json`
- 配置环境变量 `DASHSCOPE_API_KEY`（必填）
- 部署完成后拿到形如 `https://anju-zhiping.zeabur.app` 的线上地址
- 浏览器打开线上地址，确认首页与三种入口均可访问

> 备选：Railway / Render，分别用 `render.yaml` 或 `Procfile`，流程类似。

### e) 录制 Demo 视频（按脚本，可用 OBS 或手机录屏）

- 打开 `docs/DEMO_VIDEO_SCRIPT.md`，按分镜脚本录制
- 推荐工具：**OBS Studio**（电脑端，免费）或 **手机自带录屏**（移动端 Demo 时用）
- 录制前确认线上 Demo 可访问、真实 API Key 已配置
- 录制 3 个场景 + 开头 + 结尾，总时长 3 分钟左右
- 剪辑拼接（可用剪映 / Premiere / DaVinci Resolve），加背景音乐与字幕
- 导出 MP4，1080p，≤ 200MB
- 上传到 B 站 / 腾讯视频 / YouTube（任选一），设置为公开或仅限链接访问
- 复制视频链接备用

### f) 项目文档转 PDF（pandoc 或浏览器打印）

- **方法一（推荐，pandoc）**：
  ```bash
  pandoc docs/PROJECT_DOC.md -o 安居智评_项目文档_v1.pdf \
    --pdf-engine=xelatex \
    -V CJKmainfont="SimSun" \
    -V geometry:margin=2cm
  ```
  需要本机安装 pandoc + xelatex（如 MiKTeX / TeX Live）
- **方法二（浏览器打印）**：
  - 用 VS Code / Typora 打开 `PROJECT_DOC.md`，预览模式
  - 浏览器打印 → 另存为 PDF
  - 注意检查中文字体正常、表格不串行、架构图代码块完整
- 打开生成的 PDF，**逐页检查中文显示、表格、代码块、架构图**是否正常

### g) PPT 制作（按大纲，用 PowerPoint/WPS/Keynote）

- 打开 `docs/PRESENTATION_OUTLINE.md`，按 15 页大纲逐页制作
- 推荐工具：**PowerPoint** / **WPS 演示** / **Keynote**（任选一）
- 配色建议：主色 `#2E7D32`（深绿）+ 辅色 `#1565C0`（深蓝）+ 警示 `#C62828`（红）
- 字体：中文思源黑体 / 微软雅黑，英文 Inter / Roboto，字号 ≥ 24pt
- **重点页（第 11 页评审四维度）** 务必突出，建议占版面 2/3 留白
- **Demo 截图页（第 9 页）** 需在真实 Demo 部署后截取 3 张截图
- 制作完成后导出 PDF 提交，文件名 `安居智评_PPT_v1.pdf`

### h) 提交表单

- 访问提交地址：<https://page.aliyun.com/form/act1255247265/index.htm>
- 登录阿里云账号
- 按表单字段逐项填写：
  - 项目名：安居智评 Agent
  - 项目简介：参考 `PROJECT_DOC.md` 第二章一句话方案
  - 赛道：绿色发展赛道
  - 项目文档 PDF：上传 `安居智评_项目文档_v1.pdf`
  - 演示 PPT：上传 `安居智评_PPT_v1.pdf`
  - Demo 视频链接：粘贴视频网址
  - 代码仓库地址：粘贴 GitHub/Gitee URL
  - 在线 Demo 地址：粘贴 Zeabur/Railway URL
  - 团队信息：填写成员姓名、角色、联系方式
- 提交前对照「四、提交前自检清单」逐项确认
- 提交后保存提交成功截图与回执编号

## 七、常见问题与应急

| 问题 | 应急方案 |
|------|----------|
| pandoc 转 PDF 中文乱码 | 改用浏览器打印方法；或安装思源宋体后 `-V CJKmainfont="Source Han Serif SC"` |
| Zeabur 部署失败 | 检查 `DASHSCOPE_API_KEY` 是否配置；查看构建日志；备选 Railway / Render |
| 视频上传审核未过 | 检查视频无违规内容；换平台上传（B 站→腾讯→YouTube） |
| 线上 Demo 卡顿 | 检查 Zeabur 实例规格；或降级为本地录屏 + 视频展示 |
| 表单提交失败 | 换浏览器（Chrome/Edge）；清除缓存；换网络；联系赛事客服 |
| 百炼 Token 用尽 | 控制台申请扩容；或精简 Demo 流程减少调用次数 |
